# Lang Dashboard API

A REST API powering the **Lang Dashboard**, an admin platform for managing multilingual learning content. It provides secure endpoints for creating, organizing, and importing language-learning resources such as vocabulary, cities, categories, learning sets, media assets, and users.

Built with **Node.js**, **Express**, **TypeScript**, **Drizzle ORM**, and **PostgreSQL**, the API is designed for scalability and efficient bulk content management.

## Features

* 🔐 Authentication and authorization
* 📚 Vocabulary management
* 🌍 City and level management
* 🗂️ Categories and learning sets
* 🖼️ Media management (images and audio)
* 📥 Bulk Excel (.xlsx) import
* ⚡ Optimized batch imports with validation
* 🗄️ PostgreSQL database with Drizzle ORM
* 📄 RESTful API architecture
* 📝 Input validation and structured error handling
* 🚀 TypeScript-first development

## Tech Stack

* Node.js
* Express.js
* TypeScript
* PostgreSQL
* Drizzle ORM
* Multer
* XLSX
* Zod
* JWT Authentication

## Use Case

The Lang Dashboard API enables content managers to efficiently build and maintain language-learning content by providing tools to:

* Manage vocabulary entries
* Organize content into categories and learning sets
* Upload and associate media assets
* Import large datasets from Excel spreadsheets
* Support language-learning applications with a clean and scalable backend architecture
